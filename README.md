# 3D → PaperCraft MVP v2

Aquesta versió afegeix:
- simplificació configurable
- desplegament de la malla
- detecció bàsica de solapaments
- separació automàtica d'algunes costures
- línies de plegat
- numeració de cares
- SVG imprimible

Execució:
```bash
pip install -r requirements.txt
streamlit run app.py
```

Nota: les pestanyes geomètriques encara són la següent fase; aquesta versió prepara la topologia de costures.
